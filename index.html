O que é HTML?

HTML significa HyperText Markup Language. É uma linguagem de marcação usada para criar a estrutura das páginas web.

Para que serve o HTML?

Serve para organizar textos, imagens, títulos, links, tabelas e outros elementos de uma página web.

Principais etiquetas HTML

<h1> — cria um título.

<p> — cria um parágrafo.

<img> — apresenta uma imagem.

<a> — cria um link.

<body> — contém o conteúdo visível da página.

Exemplo de HTML

<h1>Olá, mundo!</h1>

Este código cria o título "Olá, mundo!".
